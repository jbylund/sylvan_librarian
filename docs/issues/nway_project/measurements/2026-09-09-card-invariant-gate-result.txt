TWO CORRECTIONS THIS FORCES.

1. THE METRIC WAS BLIND. "How much narrower can we get the spread" cannot see this fix at all: on a
   card-invariant row the realized counter is 0, so the row is excluded from any feature/realized
   ratio by the divide-by-zero guard. Setting the feature to 0 where truth is 0 is invisible to that
   metric BY CONSTRUCTION. The spread being unchanged is not evidence the fix failed.

2. THE HYPOTHESIS WAS WRONG ANYWAY. The chain was "compose grades 20.0x while candidates grades
   2.7x, because compose's fix does not cover compose -- extend card-invariance to it". The extension
   reaches 0.9% of queries, so missing card-invariance is NOT what makes compose's rows dispersed.
   The dispersed compose rows have tier > 0 and are NOT card-invariant: genuinely printing-varying
   residuals where P3 does walk spans, and where stream_scan_units falls through to the big `else`
   branch -- Round 30's redo-pass calibration, fit as a wall-clock residual because no structural
   counter existed for the redo's real work. THAT is where compose's 20x lives, and it is the next
   place to look.

KEPT OR NOT is a judgment call: correct on 69 rows, no measurable win, no measurable harm, one flip.
